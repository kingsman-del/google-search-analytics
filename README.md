# Search Intelligence — starter site

A static website to describe a personal keyword analytics project. No OAuth or API integration is present.

## Before publishing
- Support contact is set to `groverj205@gmail.com` in the HTML pages.
- Review and update the privacy policy and terms to match real project data practices.
- Keep Google OAuth credentials, API secrets and tokens out of this repository.

## Deploy to GitHub Pages
1. Create a public repository named `google-search-analytics`.
2. Upload the four HTML/CSS files (and this README) to the repository root.
3. Go to repository Settings > Pages > Build and deployment.
4. Set Source to 'Deploy from a branch', Branch `main`, Folder `/(root)` and Save.
5. Find the published site URL on the Pages settings screen.

## Google OAuth verification
A public GitHub Pages demo URL is a useful start, but Google may require your own verified custom domain. Add a domain you control, confirm it in Search Console, and use matching links in Google Auth Platform > Branding. Publishing this site does not imply OAuth verification or Ads API Basic access.
